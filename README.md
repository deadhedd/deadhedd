# deadhedd

Systems, infrastructure, and automation.

I build practical, reliability-focused tooling around Linux, OpenBSD, Git,
automation, and local-first software. I care about explicit state, conservative
failure behavior, reproducibility, observability, and keeping important data in
formats users can inspect and own.

## Selected work

- **[vaultctl](https://github.com/deadhedd/vaultctl)** — Go tooling for explicit,
  conservative synchronization of Git-backed Obsidian vaults across client and
  server repository layouts.

- **[nre](https://github.com/deadhedd/nre)** — A POSIX-shell automation runtime
  built around execution contracts, structured logging, artifact tracking, and
  predictable failure behavior.

- **[Dynamic Notes](https://github.com/deadhedd/dynamic-notes)** — A shipped
  Obsidian plugin for moving structured Markdown blocks through small local
  workflows without hidden per-note state.

- **[Symlink Notes](https://github.com/deadhedd/symlink-notes)** — A shipped
  Obsidian plugin providing portable Markdown-level shortcuts across desktop and
  mobile without filesystem symlinks.
